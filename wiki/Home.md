# Network Log Manager — Technical Wiki

> Italiano / English

Network Log Manager raccoglie log di rete, normalizza eventi MikroTik, mantiene dati online e archivi storici compressi, offre ricerca/esportazione web con RBAC/MFA e automatizza retention, backup e aggiornamenti.

Network Log Manager collects network logs, normalizes MikroTik events, maintains online and compressed historical data, provides RBAC/MFA protected web search/export, and automates retention, backup and updates.
